# Naturia app (Android)

Buy bulk dried fruit and vegetable peels and other biodegradable waste, in 25 kg and 50 kg
sacks, for farms, nurseries and compost makers. A native Android app: browse the shop, order,
sign in, and (for the shop owner) see and manage orders.

## Download

**[Download Naturia.apk](https://github.com/johniikuttann/naturia-app/raw/main/Naturia.apk)**
(version 3.0.2, 8.6 MB)

Open this page on your Android phone and tap the link above.

## Install

**Already have an older Naturia (version 2.x)?** Uninstall it first (press and hold the app, then
**Uninstall**). Version 3 is a new, native app with a new signing key, so Android will not install it
over the old one. Only your shopping bag is lost. (*"App not installed as package conflicts with an
existing package"* means the old one is still on the phone.)

1. Tap **Download Naturia.apk**. If your phone warns that this type of file can harm your
   device, tap **OK** / **Download anyway**.
2. Open the downloaded file. If Android says *"For your security, your phone is not allowed to
   install unknown apps from this source"*, tap **Settings**, switch on **Allow from this source**
   for your browser, then go back and tap **Install**.
3. If Google Play Protect shows a warning, tap **More details → Install anyway**. The app is not on
   the Play Store, which is why the warning appears. Version 3.0.1 could be blocked as "harmful"
   because it installed its own updates; 3.0.2 no longer does that (its Update button opens this page).
4. Open **Naturia** from your home screen.

Needs **Android 8.0 or newer**. You can browse without internet; **placing an order needs
internet**. Payment is Cash on Delivery, and the shop calls you to confirm.
